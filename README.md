# echoNad3

The small, single-page homepage at [echonad3.github.io](https://echonad3.github.io/).

No framework, analytics, or client-side JavaScript—just HTML and CSS.

## Local preview

Serve the repository root with any static file server, for example:

```sh
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

The site deploys directly from the `main` branch through GitHub Pages.
