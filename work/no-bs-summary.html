No BS Summary

A caption-based YouTube summarizer designed as one product across a website, Chrome side panel, installable PWA, and Android share target.

The problem

A long video should not hide a short answer.

Many videos contain useful information buried inside repetition, padding, or a structure that is difficult to scan. The product needed to extract the useful substance without forcing users into a separate, complicated workflow.

The core interaction stays deliberately small: provide or share a YouTube link, receive a structured summary, then decide whether the video is worth watching.

The product

One service, shaped for each platform.

The website accepts pasted links, the Chrome extension works inside YouTube’s side panel, and the Android app registers as a native share target for YouTube and compatible clients.

Every surface uses the same backend contract and returns the same summary model, including a direct WATCH, SKIM, or SKIP verdict with the reason behind it.

Engineering

A shared core behind four product surfaces.

Server-side boundaries

Provider credentials and product limits stay in the Cloudflare Worker instead of being exposed to clients.

Shared product model

Web, extension, and Android surfaces reuse the same client state, API contract, and summary rendering logic.

Caption-first pipeline

The service works from existing captions and rejects unsupported videos instead of pretending to understand missing content.

KV caching

Completed summaries can be reused across clients, reducing repeated work and improving response time.

Platform-specific delivery

Chrome MV3, PWA share targets, and Capacitor Android packaging each get the integration they need.

Automated guardrails

Unit tests, accessibility smoke tests, extension checks, type checking, and bundle limits protect releases.

What it demonstrates

Product architecture across browser, backend, and native delivery.

This project demonstrates API design, third-party provider integration, server-side secret handling, shared client architecture, extension development, PWA behavior, native Android integration, caching, validation, and deployment on Cloudflare.
