How I work

Useful first. Reliable all the way down.

I care about the entire path from the first product decision to the version somebody can actually install and trust.

01

Start with the real problem

I remove ceremony and features that do not help the job. The interface should make the next action obvious.

02

Own the whole product

UI, application state, backend boundaries, native packaging, tests, and release automation are one connected system.

03

Protect the user’s trust

Keep data local where possible, make recovery deliberate, minimize permissions, and avoid collecting what the product does not need.
